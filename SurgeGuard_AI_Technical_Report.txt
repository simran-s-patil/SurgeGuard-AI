1. EXECUTIVE SUMMARY
---------------------
SurgeGuard AI is a state-of-the-art, secure "Silent Bleed Detection" system 
designed for laparoscopic surgery. The system addresses the critical clinical 
challenge of occult (hidden) internal bleeding by leveraging AI-driven pixel 
segmentation while ensuring data integrity through a robust cybersecurity 
framework.

2. PHASE 1: SYNTHETIC DATA GENERATION (DATA PILLAR)
---------------------------------------------------
Since medical datasets are often restricted, we developed a proprietary 
Synthetic Data Engine (synthetic_generator.py).
- Process: Blends clean laparoscopic images with procedurally generated blood 
  masks.
- Augmentation: Uses spatial transformations (rotation, scaling) and color 
  jitter to prevent overfitting.
- Vitals Simulation: Generates 10-minute sequences of synchronized heart rate 
  and blood pressure data, simulating hemodynamic shifts during active bleeding.
- Output: Pairs of 512x512 surgical frames and binary ground-truth masks.

3. PHASE 2: AI/ML SEGMENTATION & XAI (INTELLIGENCE PILLAR)
-----------------------------------------------------------
The core intelligence is powered by a customized U-Net architecture optimized 
for real-time inference.
- Model: U-Net with Skip Connections.
- Input Resolution: Downsampled to 64x64 for ultra-low latency (<30ms).
- Loss Function: BCEWithLogitsLoss for precise binary pixel classification.
- Explainability (XAI): Implemented Grad-CAM (Gradient-weighted Class 
  Activation Mapping) to visualize "Neural Attention." This allows surgeons 
  to see the specific regions the AI is highlighting as "Bleed Risks."
- Temporal Logic: Analyzes 30-frame sequences to detect cumulative area 
  increases, triggering "Occult_Bleed_Alerts" even when bleeding is slow.

4. PHASE 3: CYBERSECURITY FRAMEWORK (SECURITY PILLAR)
------------------------------------------------------
To prevent adversarial attacks or video tampering (Deepfakes), we implemented 
a dual-layer security protocol.
- LSB Watermarking: Embeds a "Digital Seal" (SurgeGuard_Authentic) into the 
  Least Significant Bits of the video stream.
- Cryptographic Signatures: 
    * Every frame is hashed using SHA-256.
    * The hash is signed with a Secret Key using HMAC-SHA256.
    * The Command Center verifies these signatures in real-time. If a single 
      pixel is modified (adversarial attack), the "Integrity Score" drops to 
      0%, alerting the surgeon to potential tampering.

5. PHASE 4: COMMAND CENTER (INTEGRATION PILLAR)
-----------------------------------------------
The final integration provides a unified "Surgery Dashboard."
- Backend (FastAPI): A high-performance Python server that manages the model 
  inference, WebSocket streaming, and security verification.
- Frontend (Vite/React): A modern, premium UI featuring:
    * Neural Stream: Main video feed with occupancy HUD.
    * Neural Attention Map: Live Grad-CAM heatmap visualization.
    * Biological Telemetry: Real-time vitals graphing.
    * Cyber-Shield: Live tracking of hash integrity and signature status.
